# ResumeLens Pro

ResumeLens Pro is a frontend-first career intelligence dashboard for comparing a resume with target jobs, checking ATS readiness, identifying skill gaps, improving resume bullets, and preparing for interviews.

## Hackathon
Built for the SkillValix Frontend Web Development Hackathon 2026.

## Features
- Premium responsive SaaS dashboard
- Resume upload interface
- Resume health / ATS analysis
- Job description matching
- Skill gap analysis
- AI-style resume bullet improvement
- Interview preparation
- Skill roadmap
- Job comparison
- Dark/light mode
- Browser-only demo experience
- No backend required

## Tech
React, Vite, CSS, Lucide React.

## Run locally
```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build
```bash
npm run build
```

## Note
This hackathon version is a frontend prototype. Analysis screens use browser-side demo logic/data and do not claim to call a live AI backend.
